Bộ dữ liệu bảo dưỡng

Chọn hoặc kéo thả file .xlsx / .xls / .csv. Chỉ File Pool xe là bắt buộc.
Chọn cùng lúc nhiều file, hệ thống tự nhận dạng từng file theo tên file và tiêu đề cột. Hoặc tải riêng từng file ở các ô bên dưới.

Đặt lịch nhanh

Dán danh sách số khung (hoặc biển số), cách nhau bằng dấu phẩy, khoảng trắng hoặc xuống dòng, rồi chọn ngày. Các xe trong danh sách sẽ có ngày ở cột "Ngày đặt lịch". Dữ liệu được lưu trên trình duyệt.

File đã tải lên

Các file đã tải được lưu trong trình duyệt, tự nạp lại khi mở trang. Có thể nạp lại thủ công bằng nút bên dưới.
