Kiểm soát phân loại nguồn Order

Chỉ giữ Order có Depot = 1102 hoặc 1107. Depot 1107 → PLF. Depot 1102 → ghép biển số với file Xe: Tổ kết thúc 01.05 / 01.06 → RTO, còn lại → TAXI. Dòng Depot trống / mã khác bị bỏ qua, không tính vào bất kỳ tổng nào.

CHÚ THÍCH DỮ LIỆU & CÔNG THỨC: Giải thích nguồn dữ liệu, điều kiện lọc và cách tính chỉ số.

Quy ước và công thức

  • File Order: 1 file gộp. Chỉ giữ dòng có Depot = 1102 hoặc 1107; Depot trống / mã khác bị bỏ qua, không tính vào tổng.
  • Nguồn Order: Depot 1107 = PLF. Depot 1102 = ghép biển số với file Xe; Tổ kết thúc 01.05 / 01.06 = RTO, còn lại (kể cả biển số không có trong file Xe) = TAXI.
  • Order trend: dùng Create Time.
  • GMV: chỉ Status chứa COMPLET; công thức = Applicable Fee hoặc Base Fee + Surcharge Fee − Discount + Tip Amount.
  • Xe vận doanh: chỉ Trạng thái cấp 2 = Xe vận doanh.
  • Tỷ lệ hoàn thành: Order hoàn thành / Tổng Order × 100%.
  • Tỷ lệ hủy: Order hủy / Tổng Order × 100%.
  • GMV/Order hoàn thành: GMV / Số Order hoàn thành.
  • Tỷ lệ đạt định biên: Xe thực tế / Xe định biên × 100%.

Diễn giải các bảng

  • Đội/Tổ: so sánh nguồn lực, Order, GMV và hiệu quả.
  • Hiệu suất xe: phân tích theo biển số sau khi ghép dữ liệu.
  • Tài xế chưa có cuốc: tài xế được gán xe nhưng không có Order hợp lệ; Order CANCELLED không được tính là đã có đơn.
  • Hủy cuốc: phân tích địa chỉ đón, tài xế và tỷ lệ hủy.
  • XDV: hiện trạng xe nằm xưởng; số ngày tồn = hôm nay − Từ ngày; nhóm tồn 0–7 / 8–14 / 15–30 / >30 ngày (4 bậc màu); GMV mất ước tính = xe XDV × KPI GMV/xe/ngày.
  • Pool xe Depot: đối chiếu xe thực tế với định biên, thiếu/thừa và tỷ lệ đạt.

Kho dữ liệu ngày & so sánh tuần

  • Kho ngày: mỗi ngày đã khóa lưu tổng hợp Order/GMV/hủy theo giờ, nguồn, Tổ và danh sách tài xế được gán xe vận doanh (kể cả tài xế 0 đồng) theo file Xe tại thời điểm khóa. Không khóa ngày hôm nay.
  • WoW / Wo2W: kỳ chọn so với cùng kỳ lùi 7 / 14 ngày. Đủ ngày trong kho → so tổng; thiếu ngày → so bình quân/ngày; tỷ lệ so theo điểm %.
  • 0 đồng liên tiếp: số ngày liền nhau (tính lùi từ ngày chọn) tài xế được gán xe và GMV = 0; ngắt khi có GMV, không còn gán xe, hoặc ngày chưa có trong kho. Mặc định ngưỡng 2 ngày, Khẩn từ ngưỡng + 3.
  • Kiểm soát xe trong vùng: xe Trạng thái cấp 3 = Xe vận doanh (không PLF, RTO, xe ngoài file Xe). Có mặt = định vị trong vùng ≥ 30 phút/khung (bỏ lượt < 5 phút) hoặc có đơn hợp lệ (ASSIGNED / IN PROCESS / COMPLETED) tại địa bàn theo địa chỉ đón; đơn hủy là nhóm riêng, CR = hợp lệ / (hợp lệ + hủy); đơn được ghép với lượt vào vùng theo Create Time ± 10 phút (A khớp / B không định vị / C vùng khác / D không ghép được xe / E chưa có file vùng); Tuân thủ = có mặt + có định vị + có tài xế; % đáp ứng = có mặt / TX cần (số xe khác nhau cần có mặt trong khung).
  • Bình Dương: Demand = Completed + Driver Cancel; CR = Completed / Demand; Supply = số xe có Order; Trip thiếu = Demand × CR mục tiêu − Completed.
